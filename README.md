# 🍖 Kebab Empire Simulator

**The most satisfying kebab cooking idle/clicker game!**

Slice meat, assemble kebabs, grill them perfectly, serve customers and build your empire.

## Screenshots
![Kitchen](https://via.placeholder.com/600x400/FF6B00/000000?text=Kitchen+Screen)

## Tech Stack
- React Native + Expo
- Reanimated 3 + Gesture Handler
- Zustand
- Expo AV & Haptics

## Quick Start
```bash
git clone https://github.com/SADASDASDdasfasd/kebab-empire-simulator.git
cd kebab-empire-simulator
npm install
npx expo start
```
